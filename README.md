# Jay Programming Language (V7.0)

Professional, portable, and colorful.

## Installation

### Linux / macOS
```bash
cd jay-installer
sudo ./install.sh
```
*Installs to `/usr/local/bin/jay`, sets up Icons and File Associations.*

### Windows
Run `jay-installer\install.bat` as Administrator.
*Sets up PATH, Icons, and Registry associations.*

## Updating
Run `./update.sh` (Linux) or `update.bat` (Windows) to upgrade to the latest version.
