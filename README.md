# Jay Programming Language

**Jay** is a simple, portable, and beginner-friendly programming language designed to make coding easy to learn and use across different systems. It focuses on clarity, colorful syntax, and smooth installation, so users can start programming without complex setup.

---

## Features

### 1. Portable by Design

* Install and run Jay on **Linux** and **Windows**.
* Lightweight installer with easy **install, uninstall, and update** options.
* Works across systems without heavy dependencies.

### 2. Beginner-Friendly Syntax

* Simple and readable structure.
* Clear functions, loops, and conditionals.
* Designed for students and new programmers.

### 3. Built-in Functions

* Common operations available by default.
* Input/output functions ready to use.
* No need to import basic libraries.

### 4. IDE Integration

* `.jay` files show a **custom icon**.
* Automatic **syntax highlighting** for:

  * Functions
  * Loops
  * Conditionals
  * Inputs
* Works with popular IDEs like:

  * Visual Studio Code
  * Other text editors with extension support

### 5. Colorful Syntax

* Important elements are visually distinct.
* Improves readability and reduces errors.
* Helps beginners understand program flow easily.

## Installation

### Linux

```bash
chmod +x install.sh
./install.sh
```

### Windows

1. Double-click `install.bat`
2. Follow on-screen instructions
3. Restart system when prompted

---

## Uninstallation

### Linux

```bash
./install.sh uninstall
```

### Windows

```bat
install.bat uninstall
```

---

## Update

### Linux

```bash
./install.sh update
```

### Windows

```bat
install.bat update
```
